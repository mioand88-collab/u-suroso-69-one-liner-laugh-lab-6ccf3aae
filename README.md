# One-Liner Laugh Lab

A robot vacuum stands accused of eating a sock. Its defence: the sock was trespassing under the bed — unlabelled, unclaimed, and frankly delicious — so it filed a report with itself and closed it. This entry is a single deadpan one-liner answering the prompt, written by `main.ts` to `/output/entry.txt`.
